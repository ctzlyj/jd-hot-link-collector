# 素材包契约

## 目录

`<root>/<关键词>/<商品标题>/`

```
主图/主图_1.jpg ...
详情图/详情图_1.jpg ...   # 按详情文档出现顺序
SKU图/<规格名>.jpg ...    # 按前台SKU顺序命名，冲突加SKU后缀
主图视频/主图视频_1.mp4    # 无视频时保留空文件夹
商品信息.xlsx
```

## 校验

- 图片必须是真实JPEG编码（逐文件 `PIL.Image.verify()`），扩展名不算证据。
- 详情图按 `showdesc` 文档顺序提取，混合 `src/data-lazyload/url()` 均按出现顺序、去重。
- MP4做结构校验（`ftyp/moov/mdat`、时长>0），不做全帧解码。
- 商品包只在主商品与全部SKU价格证据齐时生成；标题冲突追加SKU后缀；已存在同名用户目录时报错不覆盖。
- 每个包生成receipt；`verify_batch.py` 独立从原始输入和缓存重算并逐行比对表格、图片数量、视频数量。

## 断点语义

- `data/<sku>.json`：有效价格快照，重跑跳过。
- `partial_data/<sku>.json`：缺价主数据，可用于展开真实SKU，必须继续补价；补价按提取器版本有界重查。
- `errors/PRODUCT_UNAVAILABLE`：商品级失败（下架），保留证据，重跑跳过。
- `request_clock.json`：跨进程请求间隔，恢复探测与采集进程共享，防止探测成功后立即连发。
